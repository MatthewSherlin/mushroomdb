# Performance baselines

Regenerated by hand per Plan 8 discipline. CI compiles the benches (`cargo bench --no-run`)
and does not time them.

**Machine:** Apple M4 Pro (12 cores), 24 GB RAM, macOS 15.7.3 (24G419), arm64
**Date:** 2026-08-18
**Rust:** rustc 1.92.0 (ded5c06cf 2025-12-08), cargo 1.92.0
**Harness:** `cargo bench -p core-bench --bench engine` (criterion 0.8.2, sample_size=12)

Dataset (`bench_db(10_000, 0xA5A5_5A5A_C0DE_4B1D)`): 1,666 Org + 3,333 Project + 5,001 Person
nodes with sliding-window `skills`, numeric `year`, `[lat,lon]` `loc`, and dim-64 `emb`.
People also carry `age` / `org_id` / `project_id`. People `2..=1201` KeyMatch to hub
`org-0001` (1,200 `WORKS_AT` triples); `person-0001` is kept off the hub. Rule benches
install KeyMatch `WORKS_AT` + `ON_PROJECT` and Overlap `FIT` unless noted.

Times are criterion median ± median absolute deviation (MAD).

`explain_pair_dense` T2 shape: bench-only 20k-person KeyMatch hub (one Org + 20k
People, one `WORKS_AT` rule). The T1 1.2k hub inside the 10k 3-rule graph was
~45 µs — same as the sparse pair; the BTree walk was cheap at that size. T2
before on the 20k shape was 25.752 µs ± 0.217 µs.
