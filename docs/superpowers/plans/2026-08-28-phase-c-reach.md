# Phase C Reach Track Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make mushroomdb the graph store AI agents and frameworks find and pick: LlamaIndex + LangChain integration packages, llms-full.txt, and MCP-registry submission kits.

**Architecture:** Thin Python integration packages under `integrations/`, each implementing the target framework's graph-store interface over the existing mushroomdb Python binding / HTTP API. Discoverability artifacts are generated from existing docs. Nothing in this plan touches Rust core — it runs PARALLEL to the Temporal & Memory phase with zero merge surface (new directories + docs files only).

**Tech Stack:** Python 3.11+ (venv per package; `python3 -m venv /tmp/mvenv-<name>`), existing `mushroomdb` Python binding (PyPI 0.1.2 / local maturin build) and HTTP client. No Rust changes.

**Spec:** `docs/superpowers/specs/2026-08-27-v0.2-association-engine.md` §C2, §C3, §C4 (stretch) / Gate GC (reach side).
