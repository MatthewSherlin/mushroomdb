# v0.5 Memory Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/mushroom` behave like memory instead of a demo, prove it on a live codebase graph that stays current as files move and die, and ship rule chaining so a derived edge can feed the next rule — as v0.5.0, format-stable (still V8).

**Architecture:** Four additive layers, no storage-format change. (1) Front door: skill text made truthful (mask polarity, tool args, trust model), a `UserPromptSubmit` hook that runs `mushroomdb recall <db>` so related graph facts are injected before the assistant answers, and `--version`. (2) A generic-enough `mushroomdb ingest-git <db> <repo>` ingester producing Author/Commit/File nodes, `TOUCHED` user edges, auto-FK `AUTHOR`/`TOP_AUTHOR` derived edges, a `co_changed` Overlap rule and a `knows` via-hop rule; incremental re-runs apply adds, modifies, deletes and renames so edges retract. (3) Engine: chaining = derived-edge deltas re-enter `on_edge_changed` for via-hop rules, bounded depth 4, fire-once per (rule, src) per write, cycle rejection at `create_rule`, replay-identical because it runs inside the same `apply` hooks. (4) Weight honesty: `explain` reports a score for every rule, MCP `create_rule` defaults `weight_prop` to `"weight"`, subscriptions read the rule's `weight_prop`. README first screen and a VHS tape show ingest → SET → retract → explain on this repo.

**Tech Stack:** Rust workspace (crates/cli, crates/core-api, crates/core-rules, crates/core-query, crates/server), hand-rolled CLI arg parsing (no clap), `serde_json`, `std::process::Command` for git, VHS for the GIF. No new dependencies.

**Spec:** This document is the spec (design decisions were approved in chat on 2026-09-03; the private ledger `.superpowers/sdd/2026-09-03-v0.5-memory-release/progress.md` holds the private dogfood-spike findings that motivated Tasks 2–3). Engine design source: `docs/site/roadmap-moat.md` §2 (chaining) and §3 (decay). Facts gathered at plan time live in the session scratchpad (`plan-facts-{cli,front,engine,hooks}.md`); every file:line below was verified against the tree at commit `fe7aa01`.

- **Additive JSON only.** New struct fields exposed over MCP/HTTP use `#[serde(default)]` or `Option`.
- **No new dependencies** in any `Cargo.toml`.
- **Tests first, per task.** `cargo test --workspace` green, `cargo clippy --workspace --all-targets` zero warnings, `cargo fmt --all -- --check` clean before every commit.
- **Commits:** conventional lowercase (`feat:`, `fix:`, `docs:`, `chore:`), author identity Matthew Sherlin, **no Co-Authored-By or Claude-Session trailers** (owner rule).
- **Never push a tag or main.** Branch `v0.5-memory-release`; push the branch; the owner merges and pushes `v0.5.0`.
- **Privacy.** Nothing from the two private client repositories used for dogfooding (names, paths, data) goes into the repo. Tests build their own tiny git repos in temp dirs. The README/tape run on this repository itself.
- **Honest copy.** Alpha stated plainly. No "best", no benchmark numbers, no claim that a feature exists unless the task that ships it is done.
- **Chaining scope (binding).** v0.5 chains *derived edges → via-hop rules*. Views-feed-rules (`docs/site/roadmap-moat.md` §2 "view values it updates") is explicitly deferred to v0.6 and the moat doc is updated to say so.

//! `mushroomdb recall <db>`: the body of the UserPromptSubmit hook.
//!
//! Reads the hook's JSON payload from stdin, extracts the prompt, runs a
//! text-only hybrid search over every full-text-indexed field, and prints a
//! short plain-text digest of matching nodes and their strongest edges.
//! Silent (empty output, exit 0) on any error — a recall hook must never
//! block or slow the user's prompt.
use core_api::{GraphDb, Value};
use std::collections::BTreeMap;
use std::fmt::Write as _;
use std::path::Path;

const MAX_HITS: usize = 6;
const MAX_EDGES_PER_HIT: usize = 3;
const MAX_OUTPUT_BYTES: usize = 1800;

/// Extract the prompt text from a hook payload. Accepts `prompt`,
/// `user_prompt`, and `user_input` (the docs disagree on the field name).
fn prompt_from_payload(raw: &str) -> Option<String> {
    let v: serde_json::Value = serde_json::from_str(raw).ok()?;
    for k in ["prompt", "user_prompt", "user_input"] {
        if let Some(s) = v.get(k).and_then(|x| x.as_str()) {
            let s = s.trim();
            if !s.is_empty() {
                return Some(s.to_string());
            }
        }
    }
    None
}

pub fn run_recall(db_dir: &Path, hook_stdin: &str) -> String {
    let Some(prompt) = prompt_from_payload(hook_stdin) else { return String::new() };
    if !db_dir.exists() {
        return String::new();
    }
    let Ok(db) = GraphDb::open(db_dir) else { return String::new() };
    let pairs = db.fulltext_pairs();
    if pairs.is_empty() {
        return String::new();
    }
    // Best score per key across all indexed fields.
    let mut best: BTreeMap<String, (f64, String)> = BTreeMap::new();
    for (label, field) in &pairs {
        for (key, score) in db.search_hybrid(field, &prompt, "embedding", &[], Some(label), MAX_HITS) {
            let e = best.entry(key).or_insert((0.0, label.clone()));
            if score > e.0 {
                *e = (score, label.clone());
            }
        }
    }
    if best.is_empty() {
        return String::new();
    }
    let mut hits: Vec<(String, f64, String)> = best.into_iter().map(|(k, (s, l))| (k, s, l)).collect();
    hits.sort_by(|a, b| b.1.partial_cmp(&a.1).unwrap_or(std::cmp::Ordering::Equal).then(a.0.cmp(&b.0)));
    hits.truncate(MAX_HITS);

    let mut out = format!("mushroomdb recall ({} related nodes in {}):\n", hits.len(), db_dir.display());
    for (key, _score, label) in &hits {
        let name = db
            .node_ref(key)
            .and_then(|n| n.prop("name").or_else(|| n.prop("path")).or_else(|| n.prop("title")))
            .map(|v| render(&v))
            .unwrap_or_default();
        let _ = writeln!(out, "- {key} [{label}] {name}");
        // Strongest explained edges touching this node (rule name + score).
        let mut shown = 0;
        if let Ok(rs) = db.query(
            "MATCH (a)-[r]-(b) WHERE a.id = $k RETURN type(r) AS t, b.id AS other, r.weight AS w ORDER BY w DESC LIMIT 3",
            &BTreeMap::from([("k".to_string(), Value::Str(key.clone()))]),
        ) {
            for i in 0..rs.len().min(MAX_EDGES_PER_HIT) {
                let t = rs.get(i, "t").map(render).unwrap_or_default();
                let o = rs.get(i, "other").map(render).unwrap_or_default();
                let w = rs.get(i, "w").map(render).unwrap_or_else(|| "-".into());
                let _ = writeln!(out, "    {t} -> {o} (weight {w})");
                shown += 1;
            }
        }
        let _ = shown;
        if out.len() > MAX_OUTPUT_BYTES {
            out.push_str("    …\n");
            break;
        }
    }
    out.push_str("(query the mushroomdb MCP tools before answering about these entities)\n");
    out
}

fn render(v: &Value) -> String {
    match v {
        Value::Str(s) => s.clone(),
        Value::Float(f) => format!("{f:.2}"),
        other => format!("{other:?}"),
    }
}

    file: PathBuf,
    event: String,
    command: String,
}

const HOOK_EVENT: &str = "UserPromptSubmit";
const HOOK_TIMEOUT_SECS: u64 = 5;

fn recall_hook_command(bin_cmd: &str, db_str: &str) -> String {

fn hook_entry(command: &str) -> serde_json::Value {
    serde_json::json!({ "hooks": [ { "type": "command", "command": command, "timeout": HOOK_TIMEOUT_SECS } ] })
}

/// True if any hook group under `event` contains a command hook equal to `command`.
fn settings_has_hook(root: &serde_json::Value, event: &str, command: &str) -> bool {
    root["hooks"][event]
        .as_array()
        .map(|groups| {
            groups.iter().any(|g| {
                g["hooks"].as_array().map(|hs| hs.iter().any(|h| h["command"] == command)).unwrap_or(false)
            })
        })
        .unwrap_or(false)
}

/// Add the recall hook to `settings_file` (created if absent). Idempotent.
fn merge_hook_entry(settings_file: &Path, command: &str, manifest: &mut Manifest) -> Result<(), CliError> {
    let mut root: serde_json::Value = if settings_file.exists() {
        let raw = fs::read_to_string(settings_file)
            .map_err(|e| CliError(format!("cannot read {}: {e}", settings_file.display())))?;
        serde_json::from_str(&raw)
            .map_err(|e| CliError(format!("invalid JSON in {}: {e}", settings_file.display())))?
    } else {
        serde_json::json!({})
    };
    if settings_has_hook(&root, HOOK_EVENT, command) {
        return Ok(());
    }
    if !root["hooks"].is_object() {
        root["hooks"] = serde_json::json!({});
    }
    if !root["hooks"][HOOK_EVENT].is_array() {
        root["hooks"][HOOK_EVENT] = serde_json::json!([]);
    }
    root["hooks"][HOOK_EVENT].as_array_mut().unwrap().push(hook_entry(command));
    let parent = settings_file.parent().unwrap_or(Path::new("."));
    fs::create_dir_all(parent).map_err(|e| CliError(format!("cannot create {}: {e}", parent.display())))?;
    let json = serde_json::to_string_pretty(&root).map_err(|e| CliError(format!("cannot serialize settings: {e}")))?;
    fs::write(settings_file, json).map_err(|e| CliError(format!("cannot write {}: {e}", settings_file.display())))?;
    manifest.hooks.push(ManagedHook { file: settings_file.to_path_buf(), event: HOOK_EVENT.into(), command: command.into() });
    Ok(())
}

/// Remove exactly the hook groups whose only command is `command`; drop the
/// command from mixed groups; leave everything else byte-for-byte equivalent.
fn remove_hook_entry(settings_file: &Path, event: &str, command: &str) -> Result<(), CliError> {
    if !settings_file.exists() {
        return Ok(());
    }
    let raw = fs::read_to_string(settings_file)
        .map_err(|e| CliError(format!("cannot read {}: {e}", settings_file.display())))?;
    let mut root: serde_json::Value = serde_json::from_str(&raw)
        .map_err(|e| CliError(format!("corrupt settings json at {}: {e}", settings_file.display())))?;
    if let Some(groups) = root["hooks"][event].as_array_mut() {
        for g in groups.iter_mut() {
            if let Some(hs) = g["hooks"].as_array_mut() {
                hs.retain(|h| h["command"] != command);
            }
        }
        groups.retain(|g| g["hooks"].as_array().map(|hs| !hs.is_empty()).unwrap_or(true));
        if groups.is_empty() {
            root["hooks"].as_object_mut().unwrap().remove(event);
        }
    }
    let json = serde_json::to_string_pretty(&root).map_err(|e| CliError(format!("cannot serialize settings: {e}")))?;
    fs::write(settings_file, json).map_err(|e| CliError(format!("cannot write {}: {e}", settings_file.display())))?;
    Ok(())
}

//! `mushroomdb ingest-git <db> <repo>`: build and maintain a graph of a git
//! repository. First run ingests the whole history; later runs apply only the
//! commits after the recorded `GitSync` head, so deletes and renames retract
//! or move derived edges instead of leaving them stale.
use crate::CliError;
use core_api::{default_max_edges, IngestOptions, Predicate, RuleDef, SharedDb, Value};
use std::collections::{BTreeMap, BTreeSet};
use std::path::{Path, PathBuf};
use std::process::Command;

pub const DEFAULT_MAX_COMMITS_PER_FILE: usize = 200;
const CO_CHANGE_MIN: f64 = 0.25;

#[derive(Debug, Clone)]
pub struct IngestGitOpts {
    pub repo: PathBuf,
    pub exclude: Vec<String>,
    pub max_commits_per_file: usize,
}

#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct IngestGitReport {
    pub commits: usize,
    pub files: usize,
    pub authors: usize,
    pub renamed: usize,
    pub deleted: usize,
    pub incremental: bool,
    pub rules_created: Vec<String>,
}

#[derive(Debug)]
enum Change { Added(String), Modified(String), Deleted(String), Renamed { from: String, to: String } }

#[derive(Debug)]
struct GitCommit { sha: String, author_name: String, author_email: String, ts: i64, subject: String, changes: Vec<Change> }

fn excluded(path: &str, patterns: &[String]) -> bool {
    patterns.iter().any(|p| {
        if let Some(prefix) = p.strip_suffix('/') { path.starts_with(prefix) || path.starts_with(&format!("{prefix}/")) }
        else if let Some(ext) = p.strip_prefix("*.") { path.rsplit('.').next() == Some(ext) && path.contains('.') }
        else { path.contains(p.as_str()) }
    })
}

/// `git log --reverse --name-status -M --format=<RS>%H<US>%an<US>%ae<US>%at<US>%s [range]`
fn read_log(repo: &Path, since: Option<&str>) -> Result<Vec<GitCommit>, CliError> {
    let mut cmd = Command::new("git");
    cmd.arg("-C").arg(repo).args(["log", "--reverse", "--name-status", "-M", "--no-color", "--format=%x1e%H%x1f%an%x1f%ae%x1f%at%x1f%s"]);
    if let Some(s) = since { cmd.arg(format!("{s}..HEAD")); }
    let out = cmd.output().map_err(|e| CliError(format!("cannot run git: {e}")))?;
    if !out.status.success() {
        return Err(CliError(format!("git log failed: {}", String::from_utf8_lossy(&out.stderr).trim())));
    }
    let text = String::from_utf8_lossy(&out.stdout);
    let mut commits = Vec::new();
    for block in text.split('\x1e').filter(|b| !b.trim().is_empty()) {
        let mut lines = block.lines();
        let header = lines.next().unwrap_or("");
        let f: Vec<&str> = header.split('\x1f').collect();
        if f.len() < 5 { continue; }
        let mut changes = Vec::new();
        for l in lines {
            let cols: Vec<&str> = l.split('\t').collect();
            match cols.as_slice() {
                [s, p] if s.starts_with('A') => changes.push(Change::Added((*p).to_string())),
                [s, p] if s.starts_with('M') || s.starts_with('T') => changes.push(Change::Modified((*p).to_string())),
                [s, p] if s.starts_with('D') => changes.push(Change::Deleted((*p).to_string())),
                [s, from, to] if s.starts_with('R') => changes.push(Change::Renamed { from: (*from).to_string(), to: (*to).to_string() }),
                [s, _from, to] if s.starts_with('C') => changes.push(Change::Added((*to).to_string())),
                _ => {}
            }
        }
        commits.push(GitCommit { sha: f[0].into(), author_name: f[1].into(), author_email: f[2].into(), ts: f[3].parse().unwrap_or(0), subject: f[4].into(), changes });
    }
    Ok(commits)
}

fn file_props(path: &str, commits: &[String], top_author: &str) -> Vec<(String, Value)> {
    let dir = path.rsplit_once('/').map(|(d, _)| d).unwrap_or("").to_string();
    let ext = path.rsplit_once('.').map(|(_, e)| e).unwrap_or("").to_string();
    vec![
        ("id".into(), Value::Str(path.into())),
        ("path".into(), Value::Str(path.into())),
        ("dir".into(), Value::Str(dir)),
        ("ext".into(), Value::Str(ext)),
        ("commits".into(), Value::List(commits.iter().map(|s| Value::Str(s.clone())).collect())),
        ("n_commits".into(), Value::Int(commits.len() as i64)),
        ("top_author_id".into(), Value::Str(top_author.into())),
        ("alive".into(), Value::Bool(true)),
    ]
}

/// In-memory per-file state accumulated while walking commits.
#[derive(Default, Clone)]
struct FileState { commits: Vec<String>, by_author: BTreeMap<String, usize>, n_commits: usize }

impl FileState {
    fn touch(&mut self, sha: &str, author: &str, cap: usize) {
        self.commits.push(sha.to_string());
        if self.commits.len() > cap { self.commits.remove(0); }
        self.n_commits += 1;
        *self.by_author.entry(author.to_string()).or_default() += 1;
    }
    fn top_author(&self) -> String {
        self.by_author.iter().max_by(|a, b| a.1.cmp(b.1).then(b.0.cmp(a.0))).map(|(a, _)| a.clone()).unwrap_or_default()
    }
}

pub fn run_ingest_git(db_dir: &Path, opts: &IngestGitOpts) -> Result<IngestGitReport, CliError> {
    let db = SharedDb::open(db_dir)?;
    let since: Option<String> = {
        let r = db.read();
        r.node_ref("HEAD").and_then(|n| n.prop("sha")).and_then(|v| if let Value::Str(s) = v { Some(s) } else { None })
    };
    let incremental = since.is_some();
    let log = read_log(&opts.repo, since.as_deref())?;
    let mut report = IngestGitReport { incremental, ..Default::default() };
    if log.is_empty() { return Ok(report); }

    let mut w = db.write();
    let ingest = IngestOptions::default(); // key `id`, auto-FK `_id`

    // Load existing file state on incremental runs so `commits`/`top_author` stay cumulative.
    let mut files: BTreeMap<String, FileState> = BTreeMap::new();
    if incremental {
        let rs = w.query("MATCH (f:File) RETURN f.id AS id, f.commits AS commits, f.n_commits AS n, f.top_author_id AS top", &BTreeMap::new())?;
        for i in 0..rs.len() {
            let id = match rs.get(i, "id") { Some(Value::Str(s)) => s.clone(), _ => continue };
            let mut st = FileState::default();
            if let Some(Value::List(l)) = rs.get(i, "commits") { st.commits = l.iter().filter_map(|v| if let Value::Str(s) = v { Some(s.clone()) } else { None }).collect(); }
            if let Some(Value::Int(n)) = rs.get(i, "n") { st.n_commits = *n as usize; }
            if let Some(Value::Str(t)) = rs.get(i, "top") { st.by_author.insert(t.clone(), st.n_commits.max(1)); }
            files.insert(id, st);
        }
    }

    let mut authors: BTreeMap<String, String> = BTreeMap::new();
    let mut commit_rows: Vec<BTreeMap<String, Value>> = Vec::new();
    let mut touched_edges: Vec<(String, String, String)> = Vec::new();
    let mut deleted: BTreeSet<String> = BTreeSet::new();
    let mut renamed: Vec<(String, String)> = Vec::new();

    for c in &log {
        authors.entry(c.author_email.clone()).or_insert_with(|| c.author_name.clone());
        commit_rows.push(BTreeMap::from([
            ("id".to_string(), Value::Str(c.sha.clone())),
            ("message".to_string(), Value::Str(c.subject.clone())),
            ("ts".to_string(), Value::Int(c.ts)),
            ("author_id".to_string(), Value::Str(c.author_email.clone())),
        ]));
        for ch in &c.changes {
            match ch {
                Change::Added(p) | Change::Modified(p) => {
                    if excluded(p, &opts.exclude) { continue; }
                    deleted.remove(p);
                    files.entry(p.clone()).or_default().touch(&c.sha, &c.author_email, opts.max_commits_per_file);
                    touched_edges.push(("TOUCHED".into(), c.sha.clone(), p.clone()));
                }
                Change::Deleted(p) => {
                    if excluded(p, &opts.exclude) { continue; }
                    files.remove(p);
                    deleted.insert(p.clone());
                }
                Change::Renamed { from, to } => {
                    if excluded(to, &opts.exclude) { files.remove(from); deleted.insert(from.clone()); continue; }
                    let mut st = files.remove(from).unwrap_or_default();
                    st.touch(&c.sha, &c.author_email, opts.max_commits_per_file);
                    files.insert(to.clone(), st);
                    touched_edges.push(("TOUCHED".into(), c.sha.clone(), to.clone()));
                    if incremental && w.has_node(from) { renamed.push((from.clone(), to.clone())); }
                    else { deleted.insert(from.clone()); }
                }
            }
        }
    }

    // 1. Authors and commits (auto-FK Commit.author_id → Author = AUTHOR).
    let author_rows: Vec<BTreeMap<String, Value>> = authors.iter()
        .filter(|(email, _)| !w.has_node(email))
        .map(|(email, name)| BTreeMap::from([("id".to_string(), Value::Str(email.clone())), ("name".to_string(), Value::Str(name.clone()))]))
        .collect();
    let a = w.ingest_with_edges("Author", author_rows, &ingest, &[])?;
    report.rules_created.extend(a.rules_created);
    report.authors = authors.len();

    // 2. Renames first (history follows the node), then deletes, then files.
    for (from, to) in &renamed { w.rename_node(from, to)?; }
    report.renamed = renamed.len();
    for p in &deleted { if w.has_node(p) { w.delete_node(p)?; report.deleted += 1; } }

    let mut new_file_rows = Vec::new();
    for (path, st) in &files {
        let props = file_props(path, &st.commits, &st.top_author());
        if w.has_node(path) {
            for (k, v) in props.into_iter().filter(|(k, _)| k != "id") { w.set_prop(path, &k, v)?; }
        } else {
            new_file_rows.push(props.into_iter().collect::<BTreeMap<_, _>>());
        }
    }
    let f = w.ingest_with_edges("File", new_file_rows, &ingest, &[])?;
    report.rules_created.extend(f.rules_created);
    report.files = files.len();

    // 3. Commits with TOUCHED edges (edges reference File keys, so after files).
    let touched: Vec<(String, String, String)> = touched_edges.into_iter().filter(|(_, _, p)| files.contains_key(p)).collect();
    let c = w.ingest_with_edges("Commit", commit_rows, &ingest, &touched)?;
    report.rules_created.extend(c.rules_created);
    report.commits = log.len();

    // 4. Rules + fulltext, first run only.
    if !incremental {
        let co = Predicate::Overlap { field: "commits".into(), min: CO_CHANGE_MIN };
        w.create_rule(RuleDef { name: "co_changed".into(), src_label: "File".into(), dst_label: "File".into(), predicate: co.clone(), edge_type: "CO_CHANGED".into(), weight_prop: Some("score".into()), max_edges: Some(10), approximate: false, via_label: None, via_edge: None, via_dir: None })?;
        w.create_rule(RuleDef { name: "knows".into(), src_label: "Author".into(), dst_label: "File".into(), predicate: co, edge_type: "KNOWS".into(), weight_prop: Some("score".into()), max_edges: Some(20), approximate: false, via_label: Some("File".into()), via_edge: Some("TOP_AUTHOR".into()), via_dir: Some(core_api::Direction::In) })?;
        report.rules_created.extend(["co_changed".to_string(), "knows".to_string()]);
        for (l, f) in [("File", "path"), ("Commit", "message"), ("Author", "name")] { w.enable_fulltext(l, f)?; }
        let _ = default_max_edges; // keep import used if the compiler complains
    }

    // 5. Sync marker.
    let head = log.last().map(|c| c.sha.clone()).unwrap_or_default();
    if w.has_node("HEAD") { w.set_prop("HEAD", "sha", Value::Str(head))?; }
    else { w.insert_node("GitSync", "HEAD", vec![("sha".into(), Value::Str(head))])?; }
    Ok(report)
}

pub fn format_ingest_git(r: &IngestGitReport) -> String {
    let mut out = format!(
        "ingest-git: {} commit(s), {} file(s), {} author(s){}\n",
        r.commits, r.files, r.authors, if r.incremental { " (incremental)" } else { "" }
    );
    if r.renamed + r.deleted > 0 { out.push_str(&format!("  renamed {}  deleted {}\n", r.renamed, r.deleted)); }
    if !r.rules_created.is_empty() { out.push_str(&format!("  rules: {}\n", r.rules_created.join(", "))); }
    out
}

fn parse_ingest_git(args: &[&str]) -> Result<Command, String> {
    let mut positional = Vec::new();
    let mut exclude = Vec::new();
    let mut max_commits_per_file = ingest_git::DEFAULT_MAX_COMMITS_PER_FILE;
    let mut i = 0;
    while i < args.len() {
        let a = args[i];
        if a == "--exclude" {
            exclude.push(args.get(i + 1).copied().ok_or("missing value for --exclude")?.to_string());
            i += 2;
        } else if let Some(v) = a.strip_prefix("--exclude=") {
            exclude.push(v.to_string());
            i += 1;
        } else if a == "--max-commits-per-file" {
            max_commits_per_file = args.get(i + 1).copied().ok_or("missing value for --max-commits-per-file")?.parse().map_err(|e| format!("bad --max-commits-per-file: {e}"))?;
            i += 2;
        } else if a.starts_with('-') {
            return Err(format!("unexpected flag: {a}"));
        } else {
            positional.push(a);
            i += 1;
        }
    }
    let [db_dir, repo] = positional.as_slice() else {
        return Err("ingest-git requires <db-dir> <repo-dir>".into());
    };
    Ok(Command::IngestGit { db_dir: PathBuf::from(db_dir), opts: ingest_git::IngestGitOpts { repo: PathBuf::from(repo), exclude, max_commits_per_file } })
}

Each public hook (`on_node_changed`, `on_edge_changed`, `on_node_removed`, and the backfill tail of `create_rule`) records `let cursor = self.pending_deltas.len();` at entry and, if `self.chain_depth == 0`, calls `self.chain_from(cursor, g)` at exit. `chain_from` runs levels 1..=MAX_CHAIN_DEPTH: for each delta appended since the level's cursor (fired **or** retracted), call `on_edge_changed(&d.edge_type, d.src_id, d.dst_id, g)` with `chain_depth = level` so nested calls do not re-enter chaining; stop when a level produces no new deltas.
2. **Fire-once.** `chain_fired: BTreeSet<(u32 /*rule id*/, u32 /*rule_src*/)>` cleared at each top-level entry; `on_edge_changed` skips a `(rule, rule_src)` already in the set when `chain_depth > 0` (level 0 calls are never skipped).
3. **Determinism.** Deltas are consumed in append order; rules iterate in BTree name order; nothing depends on hash order. Replay runs the identical hooks (`db.rs:2214-2216`), so replay reproduces chained edges.
4. **Cycle rejection** at `MutPreview::check_create_rule` (`db.rs:9487`): build `via_edge → edge_type` arcs from existing via-hop rules plus the candidate; DFS from the candidate's `edge_type`; if it reaches the candidate's `via_edge`, reject. Also reject `via_edge == edge_type`. Note: damping via views is out of scope; every cycle is rejected in v0.5.
5. **Deltas discipline.** Chained deltas are appended to the same `pending_deltas`, so views, markers, MVCC and subscriptions see them with no db.rs change (`db.rs:3567` drains everything).

```rust
    /// Chain derived-edge deltas appended since `cursor` into via-hop rules.
    /// Runs at most `MAX_CHAIN_DEPTH` levels; each (rule, src) fires once per
    /// top-level write. Deterministic: deltas in append order, rules in name order.
    fn chain_from(&mut self, mut cursor: usize, g: &mut GraphMut<'_>) {
        debug_assert_eq!(self.chain_depth, 0);
        self.chain_fired.clear();
        for level in 1..=MAX_CHAIN_DEPTH {
            let end = self.pending_deltas.len();
            if end == cursor {
                break;
            }
            let batch: Vec<(String, u32, u32)> = self.pending_deltas[cursor..end]
                .iter()
                .map(|d| (d.edge_type.clone(), d.src_id, d.dst_id))
                .collect();
            cursor = end;
            self.chain_depth = level;
            for (et, s, d) in batch {
                self.on_edge_changed(&et, s, d, g);
            }
            self.chain_depth = 0;
        }
    }
