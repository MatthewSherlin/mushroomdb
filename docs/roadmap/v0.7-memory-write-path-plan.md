# v0.7 Foundations and the Memory Write Path — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `remember` → `recall` work on the default memory surface, and close the three release-mechanics gates that cannot see what they guard.

**Architecture:** Three independent hygiene fixes first (version-pin scope, ignored-test visibility, defect-ledger CI), because each is small and none depends on the rest. Then the memory write path: a default memory schema expressed in the existing `Schema` type, a first-run round-trip gate *written before the fix and demonstrated failing*, then `recall` rewritten to drop its code-identifier gate, then `remember` extended with provisional subjects, optional extracted structure, real provenance, and a report return. No engine changes, no new WAL discriminant, no storage format bump.

**Tech Stack:** Rust 1.92.0 (edition 2021), cargo workspace of 10 crates; `serde_json` for MCP payloads; `bash` + `perl` for the release gates; GitHub Actions for CI. Tests are `#[test]` in `crates/*/tests/`, driven either in-process through `server::run_mcp_stdio` over `std::io::Cursor` or by spawning the real binary via `CARGO_BIN_EXE_mushroomdb`.

**Spec:** `docs/roadmap/v0.7-memory-write-path-spec.md`

## Global Constraints

Copied verbatim from the spec; every task's requirements implicitly include these.

- **Rust 1.92.0** (`rust-toolchain.toml`, `workspace.package.rust-version`). Do not raise it.
- **No new WAL discriminant.** Full-text declarations are `EnableFulltext` (12) and rules are
  `CreateRule` (3), both already in the format. Snapshot versions 5–10 stay readable. A 0.6.x
  store must open in 0.7.
- **MushroomDB never calls a model.** Extraction is the host agent's job (`docs/design.md:55`:
  *"LLM extraction is a possible later optional plugin, never core"*).
- **No destructive entity merge.** Link-first only (spec §3.3).
- **Existing stores are never silently schema-upgraded.** Declaring full-text on an existing
  store rebuilds the index at open — a measured 227 ms regression, live ledger row 36.
- **`enable_fulltext` is not idempotent** — `Err(RuleInvalid)` on an already-enabled pair,
  `Err(RuleNotFound)` from `disable_fulltext` on a disabled one. Always go through
  `apply_schema`, which applies full-text idempotently (`crates/core-api/src/schema.rs:272-281`).
- **Determinism.** Every tie in this engine breaks deterministically. `IdMap` ids are dense,
  monotonic and never reused after delete, so *the lowest live id in a set is its oldest node.*
- **Verification bar:** `cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`
  on both feature sets, and `cargo test --workspace` must be clean before any commit.
- **Commit style:** conventional, lowercase, short (`fix:`, `feat:`, `chore:`, `test:`, `docs:`).
  **No `Co-Authored-By` and no session trailers, ever** — the owner verifies this with
  `git log --format=%B | grep -ci trailer` before pushing.
- **Never run git actions beyond the commits this plan specifies.** No pushing, no tagging, no
  branch creation without the owner asking.

- [ ] **Step 1: Write the census script**

Create `scripts/ignored-test-census.sh`:

```bash
#!/usr/bin/env bash
# How many #[ignore]d tests exist, and how many does CI actually run?
#
# A gate nothing runs is indistinguishable from a gate that passes. Three
# releases reported "two of three HNSW gates red" while two of those three had
# never executed. This prints the ratio so that is never again invisible.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "$ROOT"

mapfile -t ignored < <(
  grep -rn --include='*.rs' -A3 '#\[ignore' crates/ \
    | perl -ne 'print "$1\n" if /fn\s+([a-z0-9_]+)/' \
    | sort -u
)

# Every test name named on a `--exact` line in any workflow is executed.
mapfile -t executed < <(
  grep -rhoE '[a-z0-9_]+ --exact' .github/workflows/ \
    | sed 's/ --exact//' | sort -u
)

declare -A run=()
for t in "${executed[@]:-}"; do run["$t"]=1; done

unrun=()
for t in "${ignored[@]:-}"; do [[ -n "${run[$t]:-}" ]] || unrun+=("$t"); done

echo "ignored-test census"
echo "  #[ignore]d tests in crates/ : ${#ignored[@]}"
echo "  named in a workflow         : $(( ${#ignored[@]} - ${#unrun[@]} ))"
echo "  NEVER EXECUTED ANYWHERE     : ${#unrun[@]}"
if ((${#unrun[@]})); then
  printf '    %s\n' "${unrun[@]}"
fi
echo "ignored-test-census.sh: reported (informational; does not fail the build)"
```

### Task 3: The defect ledger gate runs, and rejects a shipped deferral

**Files:**

**Why:** the script runs in **no workflow** — it is invoked by hand as "Task 12" of a release
plan. And it accepts `DEFERRED` forever: row 36 defers to `0.6.11`, which shipped two tags ago,

defect with a stale label.

- [ ] **Step 1: Write the failing test**

Add to the end of `scripts/check-defect-ledger.sh`, before its final success message, a check
that every `DEFERRED` row names a release **after** the current workspace version:

```bash
# A deferral to a version that has already shipped is an open defect wearing a
# stale label. Row 36 deferred to 0.6.11; 0.6.11 and 0.6.12 both shipped and
# this gate stayed green, because `DEFERRED*` matched and nothing read the
# target. Compare the named target against the workspace version.
ws="$(awk -F'"' '/^version = "/{print $2; exit}' "$ROOT/Cargo.toml")"
stale=0
while IFS='|' read -r row target; do
  [[ -z "${target// }" ]] && continue
  # Sorts as versions: if the target is <= the shipped workspace version it
  # cannot still be in the future.
  newest="$(printf '%s\n%s\n' "$ws" "$target" | sort -V | tail -1)"
  if [[ "$newest" == "$ws" ]]; then
    echo "check-defect-ledger.sh: row $row defers to $target, which is not after $ws" >&2
    stale=1
  fi
done < <(deferred_rows_with_targets)
if [[ $stale -ne 0 ]]; then
  echo "check-defect-ledger.sh: FAILED — a deferral target has already shipped" >&2
  exit 1
fi
```

Implement `deferred_rows_with_targets` beside the existing parser, reusing its bounded
`DEFECT-INDEX:BEGIN/END` window and its last-non-empty-cell status extraction (the Where column
contains literal `|`, which is why `$5` is not safe):

```bash
# Emits `<row number>|<version>` for each DEFERRED row that names a target.
deferred_rows_with_targets() {
  awk -F'|' '
    /DEFECT-INDEX:BEGIN/ { inside = 1; next }
    /DEFECT-INDEX:END/   { inside = 0 }
    inside && /DEFERRED/ {
      row = $2; gsub(/[^0-9]/, "", row)
      if (match($0, /DEFERRED[^0-9]*to[^0-9]*v?([0-9]+\.[0-9]+(\.[0-9]+)?)/, m))
        if (row != "") print row "|" m[1]
    }
  ' "$LEDGER"
}
```

- [ ] **Step 3: Write the module**

Create `crates/core-api/src/memory_schema.rs`:

```rust
//! The schema a memory store is created with.
//!
//! `recall` searches the pairs `fulltext_pairs()` reports, and until 0.7 the
//! only pair any memory store ever had was `Note.text`, self-declared by
//! `remember`. So `recall` could return notes and never the entities they were
//! about. This module is the answer: one `Schema` value, applied once at
//! creation, expressed entirely in types that already exist.
//!
//! It is deliberately *not* applied to an existing store on open. Declaring
//! full-text rebuilds the index at open — measured at 227 ms against 3.8 ms
//! with none (ledger row 36) — and creating a rule fires a backfill across
//! every node. An existing store is upgraded only by an explicit
//! `mushroomdb schema apply --memory-defaults`.

use crate::schema::Schema;

/// Labels the memory surface treats as entities.
```

```rust
pub fn run_schema_apply_memory_defaults(db_dir: &Path) -> Result<String, String> {
    let mut db = GraphDb::open(db_dir).map_err(|e| e.to_string())?;
    let before = db.stats();

        .map_err(|e| e.to_string())?;

        out.push_str("schema apply: already current, nothing to do\n");
        return Ok(out);
    }
    out.push_str(&format!(
        "schema apply: {} created, {} updated, {} unchanged\n",
        diff.created.len(),
        diff.updated.len(),
        diff.unchanged.len()
    ));
    for name in diff.created.iter().chain(diff.updated.iter()) {
        out.push_str(&format!("  {name}\n"));
    }
    out.push_str(&format!(

         every open from here on.\n",
        before.nodes_live
    ));
```

```rust
}

/// Drive `mushroomdb mcp <dir>` with one line per request; return the parsed
/// responses keyed by id.
fn mcp(dir: &PathBuf, calls: &[Js]) -> std::collections::BTreeMap<u64, Js> {
    let mut lines = vec![
        serde_json::json!({"jsonrpc":"2.0","id":0,"method":"initialize","params":{
            "protocolVersion":"2024-11-05","capabilities":{},
            "clientInfo":{"name":"first-run","version":"1"}}})
        .to_string(),
        serde_json::json!({"jsonrpc":"2.0","method":"notifications/initialized"}).to_string(),
    ];
    lines.extend(calls.iter().map(|c| c.to_string()));

    let mut child = Command::new(env!("CARGO_BIN_EXE_mushroomdb"))
        .arg("mcp")
        .arg(dir)
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()
        .expect("spawn mushroomdb mcp");
    child
        .stdin
        .as_mut()
        .unwrap()
        .write_all(format!("{}\n", lines.join("\n")).as_bytes())
        .unwrap();
    drop(child.stdin.take());
    let out = child.wait_with_output().expect("mcp exited");

    let mut by_id = std::collections::BTreeMap::new();
    for line in String::from_utf8_lossy(&out.stdout).lines() {
        if line.trim().is_empty() {
            continue;
        }
        let v: Js = serde_json::from_str(line).expect("each stdout line is one JSON object");
        if let Some(id) = v.get("id").and_then(|i| i.as_u64()) {
            by_id.insert(id, v);
        }
    }
    by_id
}

}
```

```rust
//! What do I already know about this?
//!
//! The 0.6.12 implementation began by extracting *identifiers* from the topic
//! — paths, `mod::name`, snake_case, backticked words — and returned nothing
//! when it found none. On a memory store that rejected every natural-language
//! topic, including a bare human name, while the note containing the word sat
//! indexed and reachable by Cypher. There is no identifier gate here.

use crate::GraphDb;
use core_storage::fs::Fs;
use std::collections::BTreeMap;

/// How many hits the digest will name.
const MAX_HITS: usize = 6;

/// Why `recall` had nothing to say — the two reasons are different advice.
#[derive(Debug)]
pub enum RecallOutcome {
    /// The store declares no full-text index, so no topic can ever match.
    NoIndex,
    /// The store can search and this topic matched nothing.
    NoMatch,
    /// The rendered digest.
    Hits(String),
}

/// Rank nodes against a free-text topic over every declared text field.
pub fn recall_digest<F: Fs>(
    db: &GraphDb<F>,
    topic: &str,
    store_label: &str,
    max_bytes: usize,
) -> RecallOutcome {
    let topic = topic.trim();
    if topic.is_empty() {
        return RecallOutcome::NoMatch;
    }

    let mut fields: Vec<String> = db.fulltext_pairs().into_iter().map(|(_, f)| f).collect();
    fields.sort();
    fields.dedup();
    if fields.is_empty() {
        return RecallOutcome::NoIndex;
    }

    // The topic goes in as written. BM25 already handles stopwords and
    // stemming, and the websearch grammar treats bare words as an implicit
    // AND — so a question narrows rather than widens. Quoting is what would
    // make "who is Matthew Sherlin?" require the punctuation too.
    let mut best: BTreeMap<String, f64> = BTreeMap::new();
    for field in &fields {
        for (key, score) in db.search_hybrid(field, topic, "embedding", &[], None, MAX_HITS) {
            let slot = best.entry(key).or_insert(0.0);
            if score > *slot {
                *slot = score;
            }
        }
    }
    if best.is_empty() {
        return RecallOutcome::NoMatch;
    }

    // Deterministic: score descending, then key ascending, matching every
    // other tie-break in this engine.
    let mut ranked: Vec<(String, f64)> = best.into_iter().collect();
    ranked.sort_by(|a, b| b.1.total_cmp(&a.1).then_with(|| a.0.cmp(&b.0)));
    ranked.truncate(MAX_HITS);

    let mut out = format!(
        "mushroomdb recall ({} related nodes in {store_label}):\n",
        ranked.len()
    );
    for (key, _) in &ranked {
        let line = match db.node_summary_line(key) {
            Some(summary) => format!("  {key} — {summary}\n"),
            None => format!("  {key}\n"),
        };
        if out.len() + line.len() > max_bytes {
            break;
        }
        out.push_str(&line);
    }
    RecallOutcome::Hits(out)
}
```

Also in this file, `describe_entity` — the shared upsert. A subject stops being provisional the

```rust
/// Create-or-update one entity, clearing any provisional mark.
///
/// Upsert semantics lived only in `tool_upsert_entity` before 0.7, so HTTP and
/// Python had no upsert and could not clear a provisional mark. One
/// implementation, every surface.
pub fn describe_entity<F: Fs>(
    db: &mut GraphDb<F>,
    key: &str,
    label: Option<&str>,
    props: &[(String, Value)],
) -> Result<bool> {
    let created = if db.has_node(key) {
        false
    } else {
        db.insert_node(key, label.unwrap_or(PROVISIONAL_LABEL))?;
        true
    };
    if !props.is_empty() {
        db.set_props(key, props.to_vec())?;
    }
    // Anything that describes a subject settles it. `remove_prop` is Ok(false)
    // when the field was absent, so this is unconditional and cheap.
    let _ = db.remove_prop(key, PROVISIONAL_PROP)?;
    Ok(created)
}
```

`has_node`/`set_props`/`insert_node` branches. Keep its namespace stamping and its
`json_to_value` conversion — only the write composition moves.
