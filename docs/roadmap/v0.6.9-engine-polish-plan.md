# v0.6.9 — engine polish: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the 0.6.9 polish bag — Cypher/Python/HTTP truth, cheap kernel speed, leftover 0.6.8 surfaces — without touching HNSW growth gates.

**Architecture:** mushroomdb is a Rust workspace. Cypher lives in `crates/core-query` (`exec.rs` identity fields, `plan.rs` `ScanKey` / `id_lookup`). Writes and `set_props` live in `crates/core-api/src/db.rs`. HNSW and MHNS blobs live in `crates/core-rules/src/hnsw.rs`. MCP listing is `ASSOCIATION_TOOLS` in `crates/server/src/mcp.rs`. HTTP is `crates/server/src/http.rs`. Python is `bindings/python/src/lib.rs`. Docs in `docs/site/*.md` are concatenated by `scripts/gen-llms-full.sh`.

**Tech Stack:** Rust workspace, PyO3, MCP stdio, Axum HTTP.

**Spec:** `docs/roadmap/v0.6.9-engine-polish-spec.md` — the spec is binding; this plan argues from it.

**Base:** `main` at tag `v0.6.8` (`4896a895`). Branch: `feat/v0.6.9-engine-polish`. Isolated `CARGO_TARGET_DIR` e.g. `target-069`.

## Global Constraints

- Version stays `0.6.8` until Task 10 bumps to `0.6.9`.
- Snapshot format stays `VERSION_9`. MHNS may go 3 → 4 (Task 8 only). `roles.json` version unchanged.
- No recall floor in `crates/sim-harness` or `hnsw_5k_1536_recall` may be lowered.
- Do not change `HnswParams` defaults (`m=16, m0=64, ef_construction=200, ef_search=400, prune=Both`).
- `git add` explicit paths only. `git -c commit.gpgsign=false commit -m "<subject>"`. No trailers.
- No competing database product names. No sidecar wall-clock numbers in product-facing files.
- Do not edit other `docs/roadmap/v0.6.*` files except the 0.6.9 spec/plan.
- Every behaviour change: write the failing test first; revert the fix to prove it fails; restore.
- Before every Rust-touching commit: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test -p <crate you touched>`.
