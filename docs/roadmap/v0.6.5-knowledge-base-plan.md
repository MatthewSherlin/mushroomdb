# v0.6.5 — the knowledge-base release: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the engine honest about the history it retains and stop it discarding history by
default; write one shared string table per snapshot instead of one copy per string column; let
`as-of` compose with role tokens and masks; add the smallest useful predicate form to role masks
with a memo so scoped readers stop paying for the mask on every call; give `serve` a restore-on-boot
path and ship an operator runbook; and cover the v0.5.x "derived edges do not survive a snapshot"
bug class with a round-trip test per rule kind. Ship 0.6.5.

**Architecture:** Seven small changes across four crates and the Python binding, plus two docs
pages. One is a **format change**: the V8 columns section stops carrying a copy of the string table
per string column and a new shared section 12 carries it once, which takes the snapshot format to
**V9** so an older binary refuses a newer store instead of silently reading empty strings. Two are
small **Rust-API breaks**: `GraphError::CommitOutOfRange` gains a `floor` field and
`GraphDb::node_history` returns `HistoryResult` like `edge_history` already does. Everything else is
additive: one JSON field on four bodies, one field on `Stats`, one optional field on `RoleDef`, one
optional MCP argument, one CLI flag. No tool is added or removed and no MCP listing moves:
`ASSOCIATION_TOOLS` stays exactly the same fifteen in the same order and `CODE_GRAPH_TOOLS` the same
three.

**Tech Stack:** Rust 1.92 workspace (`crates/core-storage`, `crates/core-api`, `crates/server`,
`crates/cli`), PyO3 (`bindings/python`), Markdown, GitHub Actions.

**Spec:** `docs/roadmap/v0.6.5-knowledge-base-spec.md`.

**Branch:** cut from `feat/v0.6.4-data-layer` (0.6.4 is on PR #18).

## Global Constraints

- **No commit trailers of any kind.** Commit with `git -c commit.gpgsign=false commit -m "<subject>"`.
- **Nothing committed names or compares against another database, graph or vector product.** The
  relational baseline is "the relational baseline" or "arm Q"; an external vector service is "an
  external vector index". The existing benchmark files that already name one are not edited, but
  `docs/site/timetravel.md:45` is (Task 1, Step 8) because this release edits that page anyway.
- **Debug builds only** unless a task says otherwise. `target/debug` has been deleted, so the first
  `cargo` command of the first task pays a cold build of roughly ten minutes. Budget for it once;
  never trigger a release build except where Task 8 names one.
- **TDD: the failing test comes first.** Every task writes its test, runs it, watches it fail for
  the stated reason, and only then implements.
- **Each task ends with its tests passing** — the exact command is named in the task's final step.
- Ships as **0.6.5**.
- **Every number in a product-facing document comes from a committed measurement in this
  repository.** Product-facing means `README.md`, `docs/site/**`, `llms.txt`, `llms-full.txt` and
  `CHANGELOG.md`. The deployment figures in the spec's §2 and §11 are a report from outside this
  repository and stay inside the roadmap document. The only new numbers permitted in `CHANGELOG.md`
  and `docs/site/durability.md` are the byte counts printed by Task 3's size test.
- **No engine behaviour changes silently.** Every behaviour change in this plan is named in the
  changelog entry Task 8 writes.

```rust
/// Every history read must say where history starts. Below the floor the error
/// names the valid range; the two reads that take no commit carry `horizon`.
#[test]
fn horizon_is_reported_by_every_history_read() {
    let dir = tmp("horizon-honesty");
    let mut db = GraphDb::open(&dir).unwrap();
    db.set_wal_archive_retention(Some(1)); // keep one archive: the floor must advance
    for i in 0..6 {
        db.insert_node("N", &format!("n{i}"), vec![]).unwrap();
        db.snapshot_with(SnapshotOptions { keep_wal: false, archive_wal: true }).unwrap();
    }
    let floor = db.wal_horizon_floor();
    let total = db.wal_total_commits().unwrap();
    assert!(floor > 0, "the retention must have advanced the floor; got {floor}");

    // (a) The two commit-less reads carry the floor.
    assert_eq!(db.node_history("n5").unwrap().horizon, floor);
    assert_eq!(db.edge_history("n4", "n5").unwrap().horizon, floor);

    // (b) The three commit-taking reads name the range they refuse.
    let want = format!("valid range is {floor}..{total}");
    for msg in [
        db.was_linked("n0", "n1", "E", floor - 1).unwrap_err().to_string(),
        db.edges_at("n0", floor - 1).unwrap_err().to_string(),
        GraphDb::open_at(&dir, floor - 1).unwrap_err().to_string(),
    ] {
        assert!(msg.contains(&want), "{msg:?} must contain {want:?}");
        assert!(msg.contains("not retained"), "{msg:?} must say what is gone");
    }

    // (c) An unpruned store reads exactly as it did before.
    let clean = tmp("horizon-clean");
    let mut c = GraphDb::open(&clean).unwrap();
    c.insert_node("N", "a", vec![]).unwrap();
    assert_eq!(c.node_history("a").unwrap().horizon, 0);
    assert_eq!(
        c.was_linked("a", "a", "E", 99).unwrap_err().to_string(),
        "commit 99 is out of range; valid range is 0..1"
    );
}
```

```rust
    assert_eq!(hits, 1, "the marker must appear once, in the shared table; got {hits} copies");
```
