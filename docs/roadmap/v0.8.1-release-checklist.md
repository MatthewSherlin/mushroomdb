# v0.8.1 — the steps only a person takes

Prepared on 2026-10-15. `main` carries the release's work through pull requests #55, #57, #58,
#59, #60, #61 and #62; this file arrives with the commit that sets every version site to 0.8.1.
Nothing has been tagged or published.

**What the green does and does not prove.** Each pull request merged on a green `ci.yml` run
(seventeen jobs). Every local result is from one macOS machine. Each rule-engine change was given
to an independent reviewer that ran a differential fuzz — the same writes against a fresh build of
the same nodes, and against a reopen — and measured the cost against `main`; each review's result
is in the ledger row it belongs to. Not run by anyone: the test suite on Windows.

## Before anything leaves this machine

A tag freezes each of these. Each is in force on `main`; tick it to accept, or change it first.

- [ ] **D1 — this is 0.8.1, a patch release.** No format version change and no input refused that
      0.8.0 accepted. Behaviour changes are corrections: derived edges are where the rule counts
      say, deletes promote and retract what they should.
- [ ] **D2 — row 107 ships as a known limit.** A store 0.8.0 snapshotted while two rules owned one
      edge keeps a too-high edge count, and a write can still remove an edge one of the rules
      counts. The changelog says so. Repair deferred to 0.8.2.
- [ ] **D3 — some writes cost more, measured.** A write to a hub with 50,000 incoming edges, beside
      a top-k rule over the same edge type that never matches it: 0.20 ms on 0.8.0, about 22 ms
      now. Deleting a via node that 50,000 sources hop through: 112–143 ms on 0.8.0, which left
      50,000 stale edges, 346–760 ms now, which removes them.
- [ ] **D4 — deferred to 0.8.2:** the via-hop top-k half of row 83, the `rebuild_rule` half of
      row 84, rows 50, 101, 102, 107 and 108, and the Low rows.
- [ ] **D5 — the `core_api` → `mushroomdb` library rename is not in this release.**
- [ ] **D6 — a store created from Python still gets no memory schema** (row 55's census lists it as
      an exemption); the CLI and server apply it.
