# v0.6.11 — time in the graph, and a smaller vector store: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: use `superpowers:subagent-driven-development`
> (recommended) or `superpowers:executing-plans` to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a calendar date a first-class way to address history, stop the vector
index paying a cache penalty that grows with the corpus, and turn the deferred open-cost
defect from a hypothesis into a measurement.

**Architecture:** Commit times live in a **sidecar** (`commit_times.bin`), never in the
WAL or snapshot, so nothing an older binary reads changes and the release carries exactly
one format change. Vector rows are stored int8 with an f32 query (asymmetric), and the
ranking the caller sees is recomputed in full precision before `k` is applied, so
quantisation accelerates the beam without becoming the final arithmetic.

**Tech stack:** Rust 1.92.0, `rkyv` 0.8, `memmap2` 0.9, `bincode` 1, PyO3 bindings via
maturin, `axum` HTTP, `proptest`.

**Spec:** [`docs/roadmap/v0.6.11-time-and-vectors-spec.md`](v0.6.11-time-and-vectors-spec.md)
— read it first. This plan argues from that spec and does not restate its decisions.

## Global Constraints

- Version stays `0.6.10` until Task 13.
- Snapshot format stays `VERSION_9` / `VERSION_10`. **WAL discriminants stay `0..=23` —
  this release adds none.** `roles.json` version unchanged.
- The only format version that may move is `HNSW_BLOB_VERSION` (`hnsw.rs:2001`), `4 → 5`,
  and only in Task 10.
- **No recall floor may be lowered**, in `core-rules` or `sim-harness`. Do not change
  `HnswParams` defaults (m=16, m0=64, ef_construction=200, ef_search=400, prune=Both).
- Every behaviour change: write the failing test first; revert the fix to prove it fails;
  restore.
- Before every Rust-touching commit: `cargo fmt --all -- --check`,
  `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test -p <crate touched>`.
- `git add` explicit paths only. `git -c commit.gpgsign=false commit -m "<subject>"`.
  **No trailers. Do not author commits as Claude.**
- No competing database product names in committed files. No sidecar wall-clock numbers in
  product-facing files.
- Any figure that is interpolated rather than measured must say so until Task 11.

- [ ] **Step 4: Implement**

Header: 4-byte magic `MTMS`, `u16` version, `u64` floor_commit, `u64` entry count. Body:
that many `(u64 commit, i64 unix_ms)` pairs, little-endian, sorted by commit. Decode
validates magic, version, and that the byte length matches the declared count exactly —
any mismatch is `GraphError::Corrupt { detail }` naming what disagreed. No panics, no
`unwrap` on caller bytes.

`push` appends and is a no-op if `commit` is not greater than `newest_commit()` — a
replayed or duplicated commit must not create a second entry.
