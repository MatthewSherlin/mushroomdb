# v0.6.2 — the proof release: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build harness v2 (long-horizon tasks, four arms, cache and adoption metrics), then change how the code graph is delivered to the agent (session brief, precise recall, pointers, one `explore` tool, CLI delivery, optional grep redirect) and measure each change, ending with the pre-registered gate verdict.

**Architecture:** The harness is Python under `benchmarks/agent-tasks/` driving `claude -p` cells and grading against executable or git-derived truth. Delivery changes are additive in `crates/core-api/src/repograph/` (new `brief` and `explore` reports, pointer rendering), `crates/server/src/mcp*.rs` (surface chosen per store, `explore` tool), `crates/cli` (new subcommands, hooks, install flags) and the skill. No engine format change.

**Tech Stack:** Rust 1.92 workspace (hand-rolled arg parsing, serde_json, no clap), Python 3.11+ harness with pytest, Claude Code 2.1.x (`claude -p --output-format stream-json`), the existing `scripts/mcp-handshake/handshake.mjs`.

**Spec:** `docs/roadmap/v0.6x-proof-spec.md` (§1 gate, §3 harness, §4 delivery). Phases 2–4 of the spec are NOT in this plan.

## Global Constraints

- Ships as **0.6.2** (patch). CHANGELOG calls the default-surface change breaking for programmatic MCP callers.
- **No engine/on-disk format change.** New node/edge types are ordinary data.
- **Nothing committed names or compares against other products** (docs, plans, skill, changelog, commits). Third-party benchmark subject repositories may be named.
- Skill files stay ≤ 6,000 bytes (`crates/cli/tests/install.rs:2633,2646`); cursor rules ≤ 60 lines.
- Every hook keeps its budget: `UserPromptSubmit` and `SessionStart` timeout 5 s, `PostToolUse` 30 s async, `PreToolUse` 5 s.
- Token budgets are enforced as bytes with `tokens × 4`: brief ≤ 4,000 B, recall ≤ 1,200 B, `explore` default reply ≤ 4,800 B.
- The harness never runs from a dirty subject clone; every cell records its own stream file; no number is quoted anywhere unless it comes from a committed `summary.md`.
- TDD: failing test first, then the smallest implementation. Conventional lowercase commit subjects. No commit trailers.
- Idempotent install/uninstall/enable/disable: every new artifact goes through the `Manifest` (`install.rs:885`).
- `--auto` resolution order (`crates/cli/src/lib.rs:147`) is unchanged.

```python
import random, statistics

def bootstrap_ci(xs: list[float], n: int = 2000, seed: int = 0) -> tuple[float, float]:
    if not xs:
        return (0.0, 0.0)
    rng = random.Random(seed)
    means = sorted(statistics.fmean(rng.choices(xs, k=len(xs))) for _ in range(n))
    return (means[int(0.025 * n)], means[int(0.975 * n) - 1])


GATE_ADOPTION = 0.80

def gate_verdict(rows: list[dict]) -> dict:
    by_arm: dict[str, list[dict]] = {}
    for r in rows:
        by_arm.setdefault(r["arm"], []).append(r)
    stock = by_arm.get("A", [])
    if not stock:
        return {"passed": False, "best_arm": None, "reasons": ["no stock arm"]}
    mean = lambda rs, k: statistics.fmean(r[k] for r in rs) if rs else 0.0
    stock_ok = {r["task"] for r in stock if r["result_subtype"] == "success"}
    verdicts = []
    for arm, rs in by_arm.items():
        if arm == "A":
            continue
        reasons = []
        if mean(rs, "score") < mean(stock, "score"):
            reasons.append(f"{arm}: correctness {mean(rs,'score'):.3f} < stock {mean(stock,'score'):.3f}")
        if mean(rs, "cost_usd") > mean(stock, "cost_usd"):
            reasons.append(f"{arm}: cost {mean(rs,'cost_usd'):.4f} > stock {mean(stock,'cost_usd'):.4f}")
        adoption = sum(1 for r in rs if r["adopted"]) / len(rs)
        if adoption < GATE_ADOPTION:
            reasons.append(f"{arm}: adoption {adoption:.0%} < {GATE_ADOPTION:.0%}")
        turned = [r["task"] for r in rs if r["result_subtype"] == "error_max_turns" and r["task"] in stock_ok]
        if turned:
            reasons.append(f"{arm}: max-turns on tasks {sorted(set(turned))} where stock succeeded")
        verdicts.append((arm, reasons, mean(rs, "score"), -mean(rs, "cost_usd")))
    passing = [v for v in verdicts if not v[1]]
    if passing:
        best = max(passing, key=lambda v: (v[2], v[3]))
        return {"passed": True, "best_arm": best[0], "reasons": []}
    best = max(verdicts, key=lambda v: (v[2], v[3])) if verdicts else (None, ["no graph arm"], 0, 0)
    return {"passed": False, "best_arm": best[0], "reasons": best[1]}
```

```rust
use super::map::{file_pagerank, SYNC_KEY};            // make file_pagerank pub(super)
use super::render::basename;

pub fn brief<F: Fs>(db: &GraphDb<F>, opts: &BriefOptions) -> BriefReport {
    let file_keys: Vec<String> = db.nodes_with_label("File").map(|n| n.key().to_string()).collect();
    let (ranked, _truncated) = file_pagerank(db, &file_keys, None);
    let mut ranked = ranked;
    ranked.sort_by(|a, b| b.1.partial_cmp(&a.1).unwrap_or(Ordering::Equal).then(a.0.cmp(&b.0)));
    let key_files = ranked.iter().take(opts.max_files)
        .map(|(k, _)| (k.clone(), role_of(db, k))).collect();
    // symbols: by incoming CALLS count, then key
    let mut syms: Vec<(String, usize, String)> = db.nodes_with_label("Symbol")
        .map(|n| (n.key().to_string(), db.in_degree(n.key(), "CALLS"), first_line(n.prop_str("signature"))))
        .collect();
    syms.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(&b.0)));
    let key_symbols = syms.into_iter().take(opts.max_symbols).map(|(k, _, s)| (k, s)).collect();
    BriefReport {
        repo: str_prop(db, SYNC_KEY, "repo").map(|p| basename(&p).to_string()).unwrap_or_default(),
        files: file_keys.len(), symbols: db.count_label("Symbol"), edges: db.edge_count(),
        last_sync: str_prop(db, SYNC_KEY, "sha").map(|s| s.chars().take(7).collect()),
        key_files, key_symbols,
    }
}
```

```rust
pub fn render_brief(b: &BriefReport, reach: &str) -> String {
    let mut out = format!("mushroomdb brief — {}{}{} files{}{} symbols{}{} edges{}\n",
        b.repo, SEP, thousands(b.files), SEP, thousands(b.symbols), SEP, thousands(b.edges),
        b.last_sync.as_ref().map(|s| format!("{SEP}synced {s}")).unwrap_or_default());
    out.push_str("key files (by centrality):\n");
    for (p, role) in &b.key_files { out.push_str(&format!("  {p}{}\n", if role.is_empty() { String::new() } else { format!(" — {role}") })); }
    out.push_str("key symbols (most called):\n");
    for (k, sig) in &b.key_symbols { out.push_str(&format!("  {k}{}\n", if sig.is_empty() { String::new() } else { format!(" — {sig}") })); }
    out.push_str(&format!("reach the graph: {reach}\n"));
    cap_bytes(&sanitize_lines(&out), MAX_BRIEF_BYTES)
}
```

```rust
pub fn identifier_terms(prompt: &str) -> Vec<String> {
    let mut out = Vec::new();
    for raw in prompt.split(|c: char| c.is_whitespace() || matches!(c, ',' | ';' | '(' | ')' | '?' | '!')) {
        let t = raw.trim_matches(|c: char| c == '`' || c == '"' || c == '\'' || c == '.' && !raw.contains('/'));
        if t.is_empty() || is_stopword(&t.to_ascii_lowercase()) { continue; }
        let code_shaped = t.contains('_') || t.contains("::") || t.contains('/') || t.contains('#')
            || (t.contains('.') && t.len() > 3)
            || raw.starts_with('`')
            || t.chars().zip(t.chars().skip(1)).any(|(a, b)| a.is_lowercase() && b.is_uppercase());
        if code_shaped && out.iter().all(|o: &String| o != t) { out.push(t.to_string()); }
        if out.len() == MAX_QUERY_TERMS { break; }
    }
    out
}
```
