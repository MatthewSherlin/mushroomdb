### Added
- **`GraphDb.to_arrow_tables()` returns the whole graph as two `pyarrow.Table`s.** `{"nodes": ..., "edges": ...}` with fixed columns: nodes are `key`, `label` and `properties` (a JSON object as text); edges are `source`, `type`, `target`, `derived`, `rule`, `weight` and `properties` (the same sorted, HTTP-format JSON, including stored rule weights and insert counts). Convert with `table.to_pandas()` or `polars.from_arrow(table)`. It holds the whole graph in memory, is refused on a `scoped()` handle, and needs `pip install pyarrow`, which stays optional. There is also an offline graph retrieval example in `examples/graph-retrieval/` (vector match, then a graph hop), and a docs page, "Arrow, pandas and polars". (PS-8)
