### Added

- **Cypher schema statements: `CREATE INDEX`, `DROP INDEX`, `SHOW INDEXES`, `CREATE CONSTRAINT`, `DROP CONSTRAINT`, `SHOW CONSTRAINTS`.** `CREATE INDEX [name] [IF NOT EXISTS] FOR (n:Label) ON (n.prop)` declares a range index (unnamed, it is `idx_<Label>_<prop>`); `CREATE CONSTRAINT name [IF NOT EXISTS] FOR (n:Label) REQUIRE n.prop IS UNIQUE` declares a unique constraint; `DROP INDEX name [IF EXISTS]` and `DROP CONSTRAINT name [IF EXISTS]` withdraw them. They go through the same calls as `enable_range_index`, `create_constraint` and the rest, so they fail with the same errors and the first one moves the store to the V11 format. Creating a name that exists or dropping one that does not is an error naming it, unless `IF NOT EXISTS` / `IF EXISTS` is given. `SHOW INDEXES` lists every index — range, equality (`eq_<Label>_<prop>`) and full-text (`ft_<Label>_<prop>`) — with `name`, `type`, `label`, `property` and `state`; `DROP INDEX` drops an equality or full-text index by that name, and refuses the index a constraint is checked against. `SHOW CONSTRAINTS` lists `name`, `type`, `label`, `property`. Range index names beginning `eq_` or `ft_` are reserved for those listed names (`enable_range_index` refuses them too), and `DROP INDEX` refuses a listed name two indexes share, naming both. For a role-bound token, a masked or a namespaced read, `SHOW` lists only the labels the caller can see a node of. A statement that changes the schema is a write: it runs through `query_write`, HTTP `/query` and MCP `query` with a full token, Bolt auto-commit and `mushroomdb query`, and is refused inside a transaction, on an `open_at` handle, in an `as_of`, masked or namespaced read, and for a role-bound token. `SHOW …` is a read and runs wherever a read does. The words are not reserved: `index`, `show`, `unique` and the rest still name properties, labels and variables.
- **Arrow: a result with no columns encodes** (a batch of zero columns and its row count), so an HTTP `/query` in the default Arrow format can answer a schema statement.
