### Added
- **Named paths `MATCH p = (a)-[:KNOWS*1..3]->(b) RETURN p`.** A path is a map `{nodes, relationships, length}`, so it renders on every surface as any map does and needs no new value type; `p.length`, `p.nodes` and `p.relationships` read it. It works with fixed and variable-length hops, chains of both, `shortestPath`, `OPTIONAL MATCH`, `WITH`, `WHERE`, `ORDER BY`, `DISTINCT`, `count(p)` and `collect(p)`. A path through a node a mask hides is dropped whole.

### Fixed
- **`RETURN DISTINCT` and grouping treated every list and map as the same value.** `UNWIND [[1],[2]] AS x RETURN DISTINCT x` returned one row; it now returns two, and a map or list used as a group key groups by its contents.
