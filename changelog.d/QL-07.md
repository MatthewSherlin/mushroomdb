### Added
- **Named paths `MATCH p = (a)-[:KNOWS*1..3]->(b) RETURN p`.** A path is a map `{nodes, relationships, length}`, so it renders on every surface as any map does and needs no new value type; `p.length`, `p.nodes` and `p.relationships` read it. It works with fixed and variable-length hops, chains of both, `shortestPath`, `WITH`, `WHERE`, `ORDER BY`, `DISTINCT`, `count(p)` and `collect(p)`, and with `OPTIONAL MATCH` for fixed-length hops. A path through a node a mask hides is dropped whole. A path name that is already bound is an error.

### Fixed
- **`RETURN DISTINCT` and grouping treated every list and map as the same value.** `UNWIND [[1],[2]] AS x RETURN DISTINCT x` returned one row; it now returns two. A list or map used as a group key groups by its contents with the same equality as `=`: `[2]` and `[2.0]` are one value, so are `[0]` and `[-0.0]` and two `DateTime`s at one instant, `Int`s past 2^53 stay apart, and nulls group together. The same equality now applies to a number used directly as a key (`0` and `-0.0`, and `Int`s past 2^53).
