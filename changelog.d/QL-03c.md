- **Cypher list and map functions `head`, `tail`, `last`, `range`, `keys` and `properties`.** `head` and `last` give null on an empty list; `tail` of an empty or one-element list is `[]`. `range(start, end[, step])` includes the end, takes a negative step, and is an error for a step of 0, and for a result of more than 10,000,000 elements (the cap). `keys` and `properties` read a node, a relationship or a map, in key order, and list every property, so a vector-valued property (an embedding) shows like any other list; a node the scope hides, or a null binding, gives null. A null or wrongly-typed argument gives null.
