### Added
- **`EXPLAIN` returns a statement's plan without running it.** `EXPLAIN <statement>` gives a one-row `plan` column holding the plan as JSON on every surface (embedded, HTTP `/query`, Python, TypeScript, MCP); over Bolt it returns no records and the plan in the closing `SUCCESS` as `plan` (`operatorType`, `args`, `identifiers`, `children`), so drivers' `summary.plan` works. It never executes and never writes: reads, `UNION`, `CALL`, every write form (the `MATCH` part and the write operators), `UNWIND` writes and schema statements all have plans, and it is a read wherever a read is allowed, transactions and role-scoped callers included. A lookup names the index it reads (`index`: an equality index, a range index, `"key"`, or `null` for a scan), and a scoped caller sees only indexes `SHOW INDEXES` would list for it. The JSON is a diagnostic whose shape may change between releases. `PROFILE` is refused: `not supported in mushroomdb 0.10: PROFILE`. (QL-11)
