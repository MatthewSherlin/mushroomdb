### Added
- **Cypher list comprehensions `[x IN list WHERE pred | expr]`.** Both the `WHERE` and the `| expr` parts are optional, and a comprehension works in `WHERE`, `RETURN`, `ORDER BY`, `UNWIND`, a `SET` value and as a function argument, and nests. The variable is visible only inside the comprehension and shadows an outer variable of the same name there. A null list gives null; a null element is kept as an element, and a `WHERE` that is null drops it. A comprehension in the `RETURN` of a write statement is refused by name before anything is written.
