- **Backup bucket lease**: continuous backup takes an advisory lease (`<prefix>/LEASE`) before uploading. A second instance on the same prefix uploads nothing, reports backup unhealthy naming the holder, and takes over within one TTL once the holder stops renewing. On AWS S3, R2 and MinIO the lease uses conditional PUT, so two instances started together get exactly one lease. A holder that cannot renew stops writing before its lease can be taken over. New variable `MUSHROOMDB_BACKUP_LEASE_CONDITIONAL` (`on` by default; `off` makes the lease best-effort, for services that reject conditional headers). `MUSHROOMDB_BACKUP_LEASE_TTL` must now be at least 1
