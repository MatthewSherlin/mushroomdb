### Added
- **The openCypher TCK runs against every change, and its pass rate can only rise.** The TCK (tag `2024.3`, Apache-2.0) is vendored unmodified in `vendor/opencypher-tck/`, and the new `tck-runner` crate runs its 3,897 scenarios, each against a fresh store, in seconds. `docs/site/conformance.md` is generated from one run (`cargo run --release -p tck-runner -- --report docs/site/conformance.md`) and gives the pass, fail and skip counts by area and by feature file, the causes of the failures, and every function a TCK query calls. A scenario is skipped only when it uses a feature 0.10 deliberately does not have (CALL and EXISTS subqueries, FOREACH, more than one label, pattern predicates, spatial values, Time / LocalTime / named time zones, PROFILE, user-defined procedures), each rule with its reason and count. The first baseline is 712 passed, 2,612 failed, 573 skipped: a pass rate of 21.4%, recorded in `tck-baseline.txt`. CI fails when the rate drops below it and prints the new rate when it rises; the baseline is raised by an ordinary change. (QL-10)
