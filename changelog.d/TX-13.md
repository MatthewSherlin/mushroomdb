- **Bolt ROUTE**: `ROUTE` answers with a single-server routing table (ttl 300 s) naming this server's advertised address for the write, read and route roles, so routing-scheme URIs connect. The advertised address comes from config and is never a wildcard: a server bound to all interfaces must be given the host clients reach it by. A request for the drivers' default database, an empty or null name, or the store name selects the store; any other name is refused as database not found.
