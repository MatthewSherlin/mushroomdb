### Added
- **Cypher temporal functions `date`, `localdatetime`, `datetime` and `duration`.** Each takes an ISO 8601 string or a map (`date({year: 2024, month: 3, day: 15})`, `duration({days: 3, hours: 2})`), or a temporal value to convert; with no argument `date()`, `localdatetime()` and `datetime()` give the current UTC instant. A null argument gives null; an unparseable string, an out-of-range or unknown map field, or a wrongly-typed argument is an error (see QL-TF). A `datetime` string with no offset is read as UTC. A temporal value `+` or `-` a duration moves it (months first, a day past a shorter month's end lands on its last day; a date ignores the duration's time part); durations add, subtract, and scale by a number; `toString` gives the ISO text. They compare with `<`, `=` and the rest within their own type, and sort in `ORDER BY`. `time()` and `localtime()` fail with `not supported in mushroomdb 0.10: time types`. A query can return a temporal value, and storing one (`SET n.d = date(…)`) moves the store to the V11 snapshot format (see the V11 entry).
