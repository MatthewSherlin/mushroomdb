### Added
- **Cypher `MERGE` with a relationship.** `MERGE (a:L {id: 'x'})-[:T]->(b:M {id: 'y'}) [ON CREATE SET …] [ON MATCH SET …] [RETURN …]` finds or creates both nodes by key and the edge between them, in one write batch. Running it again changes nothing and never duplicates the edge; `ON MATCH SET` runs when the whole pattern already existed, `ON CREATE SET` otherwise, and a `SET` item may name either node. `<-[:T]-` is supported; undirected, variable-length, alternative-type and multi-relationship patterns are refused by name. It runs inside an interactive transaction (buffered) and under a role-scoped write (both labels and the edge type must be in scope). (QL-08).
