### Added
- **Prometheus metrics**: `GET /metrics` with `Accept: text/plain` (or `application/openmetrics-text`) answers in the Prometheus text exposition format, `Content-Type: text/plain; version=0.0.4`, with `HELP` and `TYPE` for every metric and no labels: `mushroomdb_nodes_live`, `_nodes_tombstoned`, `_edges_live`, `_commits_total`, `_wal_size_bytes`, `_rss_bytes`, `_process_start_time_seconds`, `_slow_queries_total`, `_http_transactions_open`, and on a server running continuous backup `_backup_upload_errors_total`, `_backup_last_success_timestamp_seconds`, `_backup_lag_seconds`, `_backup_healthy` and `_backup_lease_held`, and with the Bolt listener on `_bolt_connections_open` and `_bolt_connections_accepted_total`. JSON stays the default and is unchanged, and the auth rule is the same (role tokens and the write and read key tiers get 403)
