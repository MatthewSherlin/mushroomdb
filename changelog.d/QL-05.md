### Added
- **Cypher `REMOVE` for properties.** `MATCH … [WHERE …] REMOVE n.prop [, m.prop …] [RETURN …]` removes node properties through the same write path as `remove_prop`: rules re-evaluate and retract the edges that depended on the property, a missing property is a no-op, and a view-owned property or `ns` is refused as before. `REMOVE n:Label` is refused by name (a node has one label in 0.10). Inside an interactive transaction `REMOVE` buffers like `SET`. (QL-05).
