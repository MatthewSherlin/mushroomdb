### Added
- **Python interactive transactions.** `with db.transaction() as tx:` runs a block as one commit (commit on a clean exit, rollback and re-raise on an exception), and `db.begin_transaction()` returns the same `Transaction` for manual control: `tx.execute(cypher, params=None)`, `tx.commit()` (returns the commit number) and `tx.rollback()`. Reads see the transaction's own writes, nothing is visible to other handles until commit, and a commit that lost a race raises the new retryable `TransactionConflict` (a `CasConflict`); a finished transaction raises `TransactionClosed`. `close()` raises while a transaction is open. (TX-2b).
