### Added
- **CI runs the official Python driver 6.4.1 and the official JavaScript driver 6.2.0 against `mushroomdb serve --bolt-port`, twelve scenarios each, in a new `bolt-compat` job.** Connect, a refused token, auto-commit reads and writes, explicit and managed transactions (including `MATCH (a {id: $a}), (b {id: $b}) CREATE (a)-[:K]->(b)` in a managed write), 1000 rows streamed 100 at a time, every value type including date, date-time, duration and bytes, a commit conflict the driver retries, `CALL db.labels()` and a role token's view, the routing scheme through `ROUTE`'s advertised address, and a bookmark carried from one session to another. Each scenario checks the values it gets back. `docs/site/bolt.md` has a "Driver compatibility tests" section listing them and where these drivers meet the query language's current limits. (TX-18)
