### Added
- **Interactive transactions over HTTP**: `POST /tx/begin`, `POST /tx/{id}/run`, `POST /tx/{id}/commit`, `POST /tx/{id}/rollback`, `DELETE /tx/{id}` and `GET /tx/{id}` hold a multi-statement transaction in the server's memory, the routes the TypeScript client's `beginTransaction` and `transaction` call. A transaction belongs to the credential that began it (anyone else gets 404), is rolled back after `MUSHROOMDB_TX_TIMEOUT_SECS` idle seconds (default 30; 410 afterwards), and at most `MUSHROOMDB_TX_MAX` (default 100; 503 with `Retry-After` beyond it) are open at once. A commit conflict is 409 and transient; a second request on a transaction that is still running is 409 "transaction busy". Commit returns `bookmark` (the commit number) and `bookmark_text` (`mushroomdb:commit:<n>`, the text a Bolt `COMMIT` returns). A role token or `read`-tier key may begin a transaction and read through its role's mask, but a write inside it is 403. Open transactions are rolled back when the server starts shutting down, and a `begin` then is 503. See [HTTP API](docs/site/http.md).
