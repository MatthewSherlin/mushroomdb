### Added

- **Cypher list and map literals**: `[1, 2, n.x]` and `{a: 1, `b c`: n.x}` work anywhere an expression does — `RETURN`, `WITH`, `WHERE … IN [..]`, `ORDER BY`, `UNWIND`, function arguments, `CASE`, and the right-hand side of `SET`. Elements are any expression and nest freely; `head([1, 2, 3])`, `keys({a: 1})` and `UNWIND [n.x, n.x + 1] AS y` now work on literals. A trailing comma and a duplicate map key are parse errors; a null element is a query error because a stored list or map cannot hold null. Backtick-quoted identifiers (`` `c d` ``) now lex.
