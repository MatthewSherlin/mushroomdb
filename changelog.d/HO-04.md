### Added
- **Write-tier access keys: `keys.json` beside the store.** Each entry gives a token a tier. `admin` is full access, `write` may read and mutate but is refused `/backup`, `/stats`, `/metrics`, `/watch` and `/subscribe`, and `read` with a `role` is that role's masked view. Keys work on HTTP and as Bolt `HELLO` credentials with the same tiers, and add to `MUSHROOMDB_TOKEN` and `MUSHROOMDB_ROLE_TOKENS` rather than replacing them. SIGHUP re-reads the file without a restart; a file that does not parse stops `serve` at startup, or keeps the old keys on reload, and removing every key locks the server rather than opening it. New library API: `mushroomdb::AccessKeys`, `server::router_with_access_keys`, `server::watch_sighup`. (HO-04).
