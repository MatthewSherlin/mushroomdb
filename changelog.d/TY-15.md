- **Breaking**: The public Rust `Value` enum includes `Date`, `LocalDateTime`, `DateTime`, `Duration` and `Binary`; exhaustive matches must handle the new variants.
- **Breaking**: Typed Python results use native date/time/byte values and the public immutable `mushroomdb.Duration(months=, days=, nanos=)` class; callers expecting a string or `None` for a duration must handle that value type.
- **Breaking**: Storing a new property type or declaring a unique constraint or range index opts that store into sticky V11, unreadable by 0.9.x. Opening a store alone does not opt in; stores using no V11 feature stay V9/V10-readable.
