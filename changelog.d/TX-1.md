### Added
- **Interactive transactions in the Rust API.** `SharedDb::begin_transaction()` returns an owned, `Send` `Transaction` (it holds its own clone of the handle, so it can be stored or moved between threads while open): `execute` runs Cypher against a snapshot frozen at BEGIN with the transaction's own writes visible, `commit` submits everything as one WAL `Batch` frame (one commit number) and returns that number, and `rollback` (or dropping it) writes nothing. Isolation is snapshot isolation: a commit fails with `CasConflict` when any node it read or wrote changed after BEGIN; write skew through a label scan is possible. Rule-derived edges from a transaction's own writes appear only after it commits. Every write statement auto-commit runs, except a schema statement, runs inside a transaction (TX-MW).
