#### BREAKING

- **`Value` gains a `Null` variant.** It is the null element of a query-built list or map (`[1, null]`, `{a: n.missing}`) and is never stored. A Rust `match` over `Value` needs a new arm. `Null` is always the last variant; its serde form is a plain unit variant (`"Null"` in the externally tagged JSON a `/subscribe` query row carries, bincode tag 6).
- **`null` is a reserved word in Cypher.** Like `true` and `false`, it can no longer name a variable or an alias: `RETURN 1 AS null`, `MATCH (null:L)` and `UNWIND … AS null` used to parse and are now parse errors. `n.null` and a backtick-quoted `` `null` `` map key still work.

### Added

- **Cypher `null` literal and nulls inside lists and maps**: `RETURN null`, `WHERE null IS NULL`, `[1, null, 'a']`, `{a: null}` and `[n.x, n.missing]` now evaluate instead of failing. A null element stays null in every output: `Value::Null` in Rust, `null` in HTTP JSON and TypeScript, `None` in Python, `[1, null]` in Arrow's list text. `size([null])` is 1, `head([null, 1])` is null and `keys({a: null})` is `['a']`.
- **Comparisons with null are three-valued**: `x = null`, `x <> null`, `x < null` and the rest are null, so a `WHERE` drops the row, with or without `LIMIT` and with or without an index. List and map equality follows openCypher: `[1, null] = [1, null]` is null and `[1, null] = [2, null]` is false. A null element and a missing property agree: `[n.missing] <> [5]` drops the row, as `n.missing <> 5` does.
- **Cypher queries without `MATCH`**: a read may begin with `RETURN`, `UNWIND` or `WITH`. `RETURN 1 + 1 AS x`, `UNWIND [1, 2, 3] AS x RETURN x` and `WITH 1 AS a RETURN a` run against one empty row and read nothing from the graph.

### Changed

- **A stored property still cannot be null**: writing a list or map property that holds a null, whether from `CREATE (:L {p: [1, null]})`, `SET n.p = [1, n.missing]`, a `$param` or the Rust API, is refused with `a property value cannot contain null`, and nothing is written. Before this change, a null element was a query error even in a read.
