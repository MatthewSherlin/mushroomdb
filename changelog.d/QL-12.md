### Added
- **Cypher `CALL ns.name(args) [YIELD f [AS a], …] [WHERE …] [RETURN …]` runs built-in procedures.** A call is a read statement of its own and runs on every read entry point: `query`, `query_write`, read-only (`open_at`) handles and `query_at`, masked and role-scoped reads, the lock-free reader, transactions, HTTP `/query`, Bolt `RUN` and the MCP `query` tool. Arguments are expressions, `$parameters` included; `YIELD` picks and renames columns and names a column the procedure does not return; under a role, mask or namespace a procedure sees only what the caller can see. This release ships `db.ping()`; an unknown procedure is `unknown procedure: <ns>.<name>`. `CALL`, `YIELD` and `LOAD` stay ordinary names elsewhere. (QL-12)
- **openCypher forms the engine does not run are refused by name: `not supported in mushroomdb 0.10: <feature>`.** Covered: `FOREACH`, `EXISTS { }`, `COUNT { }` and `COLLECT { }` subqueries, `CALL { }` subqueries, `CALL` inside a larger query, `SET n:Label`, label predicates (`WHERE n:Label`), more than one label (`(n:A:B)`), pattern predicates (`WHERE (n)-->()`) and pattern comprehensions, `RETURN *` / `WITH *`, map projections, the `=~` operator, `LOAD CSV`, `USE`, a leading `OPTIONAL MATCH`, `MATCH … CREATE` / `MATCH … MERGE` (the refusal names `UNWIND [1] AS _ MATCH … CREATE …`, which runs today) and `allShortestPaths`, beside the existing `REMOVE n:Label`. Each used to be an unexpected-token parse error. (QL-12)
