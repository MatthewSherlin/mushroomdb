### Fixed
- **A write after `OPTIONAL MATCH` skips the rows where the node is null.** `OPTIONAL MATCH (n:Missing) SET n.x = 1`, `… REMOVE n.x`, `… DELETE n`, `… DETACH DELETE n` and `MATCH … OPTIONAL MATCH … SET` were a parse error; they now run in auto-commit and inside a transaction, write only the rows that found a node, and count only real writes. `DELETE r` on a null relationship is skipped. A `CREATE` or `MERGE` of a relationship from a null node is an error that says the node is null. The openCypher TCK pass rate rises from 0.6017 to 0.6035 (strict 0.5966 to 0.5984). (QL-ON)
