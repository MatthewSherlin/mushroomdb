### Added

- **HTTP `/schema/indexes` and `/schema/constraints`, and `mushroomdb schema indexes|constraints`.** `GET`, `POST` and `DELETE /schema/indexes[/{name}]` and `/schema/constraints[/{name}]` list, declare (`kind` `range` or `equality`; `type` `unique`) and drop indexes and unique constraints through the same code as the Cypher DDL, so a row has the fields `SHOW INDEXES` / `SHOW CONSTRAINTS` give and a role-bound token or `read` key lists only what `SHOW` shows it. `POST` and `DELETE` need a full token or an `admin` or `write` key (a role token or `read` key gets 403); a bad body or reserved name is 400, an existing name or an index a constraint backs is 409, a missing name is 404. `mushroomdb schema indexes <db-dir>` and `schema constraints <db-dir>` print the table, opening the store read-only so they run beside a server. New on the Rust handle: `schema_create_range_index`, `schema_create_equality_index`, `schema_drop_index`, `schema_create_constraint`, `schema_drop_constraint`.
- TypeScript client: `indexes()`, `createIndex()`, `dropIndex()`, `constraints()`, `createConstraint()`, `dropConstraint()` wrap the new routes.
