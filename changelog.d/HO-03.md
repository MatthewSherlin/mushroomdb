### Added
- **CORS via `MUSHROOMDB_CORS_ORIGINS`.** Unset, the server sends no CORS headers, as before. `*` allows any origin without credentials; a comma-separated list of `scheme://host[:port]` origins allows exactly those, with credentials. Preflight `OPTIONS` is answered without a token; the request that follows is still authenticated. A malformed list stops `serve` at startup, before the store is opened. (HO-03).
