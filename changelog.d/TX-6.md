- **A reader's `node_edges` and `node_edges_scoped` now say which edges a rule derived.** A lock-free `reader()` snapshot reported `derived: false` for every edge, on a store with no snapshot too, where the write handle reported `true`. The reader now reports the same flag as the write handle, including for edges derived since the last fold and edges a snapshot carries (row 114).
- **The lock-free reader no longer loses a derived edge that one batch retracts and re-derives.** A batch that moved a node off a rule's match and back left the reader without that edge (in the unfolded tail) or reporting it as not derived (after the next fold) until a reload; HTTP read routes use the reader. Present in 0.9.x (row 117).
