### Added
- **Kubernetes manifest.** `deploy/k8s/statefulset.yaml` runs mushroomdb as a one-replica StatefulSet with a ReadWriteOnce volume, `/ready` and `/health` probes, a hardened container and resource requests. The token is read from a Secret you create first (`mushroomdb-token`), so the pod will not start without it. `fsGroup` lets the non-root image write its volume. (HO-13).
- **`serve` refuses the placeholder token.** A token equal to the documentation placeholder `<set-me>`, from `--token` or `MUSHROOMDB_TOKEN`, stops `serve` with status 1 before the store is opened. (HO-13).
