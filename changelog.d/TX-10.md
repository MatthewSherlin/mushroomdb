- **Bolt connection actor**: the Bolt crate now has the per-connection state machine. `HELLO` authenticates with a mushroomdb token (`basic` and `bearer` take the token from `credentials` and ignore `principal`); like the HTTP layer, a server with no tokens configured accepts every client as full access, and one with tokens refuses `scheme: none`. `RESET` rolls back an open transaction and returns to ready, `GOODBYE` closes, and a failed login gives one answer whether or not the token exists. Keep-alive chunks between messages are skipped; a protocol violation closes the connection; a client that stalls before `HELLO`, mid-message, or never reads is dropped on a deadline; and a response value the wire format cannot carry is refused with a `FAILURE` instead of a corrupt frame.
