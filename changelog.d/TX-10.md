- **Bolt connection actor**: the Bolt crate now has the per-connection state machine. `HELLO` authenticates with a mushroomdb token (`basic` and `bearer` take the token from `credentials` and ignore `principal`; `none` works only when unauthenticated access is enabled explicitly), `RESET` rolls back an open transaction and returns to ready, `GOODBYE` closes, and a failed login gives one answer whether or not the token exists. Keep-alive chunks between messages are skipped, and a response value the wire format cannot carry is refused with a `FAILURE` instead of a corrupt frame.
