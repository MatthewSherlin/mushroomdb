### Fixed
- **`same_as_pairs` no longer reads a failed read as "not linked"** (defect-ledger row 51). It returns a `Result`: a key that does not exist is still skipped, any other read error is returned. `remember` and `upsert_entity` propagate it when it happens before the write; when it happens after the commit they still return `Ok` and set the new `same_as_unread` field (the error text, `null` otherwise) in the Rust report, the MCP reply and the Python dict, so an empty `same_as` / `same_as_lost` is never mistaken for "nothing changed".
