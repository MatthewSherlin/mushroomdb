- Continuous S3/R2/MinIO backup: WAL segments shipped at ~1 s cadence; snapshots uploaded automatically
- Following another process's writes: a handle now notices when a peer's snapshot replaced `wal.bin`, by file identity on Unix, and reloads instead of reading or appending at the old offset in the new file. Before every write the identity is checked, so a replacement of the same length is caught too; other platforms keep the length checks
